## How to use

1. Do one day at a time; try each problem for 30–45 minutes before reading a solution.
2. Re-read the matching topic folder README (e.g. `two_pointers_sliding_window/`) before a new topic day.
3. After solving, compare with the solution file and note the pattern in [PATTERNS_CHEATSHEET.md](../PATTERNS_CHEATSHEET.md).
